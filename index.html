SOC137

Malicious File/Script Download Attempt

MalwareTrue PositiveT1204

Macro-enabled invoice document (.docm) used an AutoOpen macro to invoke PowerShell and download a second-stage payload. Device blocked the file before execution.

C2 requested? Not Accessed
Malware analysis: Malicious
Remediation: Quarantined

Objective: Determine whether the downloaded file was malicious and whether it executed or reached a C2.

Investigation: Reviewed the blocked file and performed hash analysis. Found an AutoOpen macro in NewMacros.bas using Shell to invoke PowerShell and download a second-stage payload. Endpoint checks confirmed the file was never opened and no outbound traffic occurred.

Evidence: File: INVOICE PACKAGE LINK TO DOWNLOAD.docm (16.66 KB) · Device action: Blocked · Source: 172.16.17.37

Verdict: True Positive — Malicious, quarantined, no host impact.

MITRE ATT&CK: T1204 — User Execution

Key takeaway: Macro-enabled documents can act as an initial execution mechanism. Correlating file analysis with endpoint and network activity confirmed the threat was blocked before causing impact.

SOC138

Detected Suspicious XLS File

MalwareTrue PositiveT1112

Malicious Excel macro workbook exploited CVE-2017-11882, executed an encoded PowerShell payload, and generated outbound traffic consistent with C2 communication.

C2 requested? Accessed
Malware analysis: Malicious
Remediation: Not Quarantined

Objective: Determine whether the suspicious XLS file was malicious, identify attack activity, and establish whether the endpoint communicated with a C2.

Investigation: Analyzed the file hash in VirusTotal — 45/64 vendors flagged it as malicious. Investigated host Sofia and found an obfuscated PowerShell command using -ENCOD. Network logs revealed outbound connections and a malicious C2 URL.

Evidence: File: ORDER SHEET & SPEC.xlsm (2.66 MB) · MD5: 7ccf88c0bbe3b29bf19d877c4596a8d4 · Host: Sofia · Network: 177.53.143.89:443, 35.189.10.17:80

MITRE ATT&CK: T1112 — Modify Registry

Key takeaway: File analysis alone was insufficient. Correlating VirusTotal results, endpoint activity, PowerShell execution, and network logs was needed to confirm the full scope of the incident.
